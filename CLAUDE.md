# staymo-code

This repo holds only the site's JS/CSS modules, served via jsDelivr by tag (see README.md for layout, conventions and the release flow). Code changes, tests and tags are done here.

Anything about the live site (Webflow pages, embeds, staging, publishing, project docs and rules) is done from the private repo `Dmitry-Wide/staymo-site`, not here: it has the project docs and the Webflow skills, and this public repo intentionally carries neither.

A session opened in staymo-site cannot push here (its sibling clone is read-only), so a code change is its own session in this repo.
